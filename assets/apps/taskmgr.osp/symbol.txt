# EIN SAEULENDIAGRAMM IN EINEM RAHMEN. Es ist das Bild, das jedes System
# fuer diese Sache nimmt, und zwar nicht aus Bequemlichkeit: was der
# Aufgabenverwalter zeigt, sind Balken verschiedener Hoehe, und genau das
# ist hier gezeichnet. Ein Zahnrad waere ein Einstellungssymbol, eine
# Lupe ein Suchsymbol.
#
# ROLLEN STATT WERTEN (Runde NETVIEW, Nachtrag): keine der Farben steht
# als Zahl da. `@ink` ist die Vordergrundfarbe des laufenden Schemas,
# `@dim` die gedaempfte, `@accent` die Akzentfarbe -- damit ist dieses
# Symbol im hellen UND im dunklen Schema richtig, ohne ein zweites
# Exemplar. Ein Symbol mit eingebautem Grau ist im Dunkelmodus ein
# grauer Fleck.
#
# KEIN FREMDES BILD. Diese sechzehn mal sechzehn Zeichen sind in dieser
# Runde entstanden; es ist kein Symbol aus einem fremden Satz
# abgezeichnet, und damit haengt an diesem Buendel keine fremde Lizenz.

# I = @ink
# D = @dim
# A = @accent
