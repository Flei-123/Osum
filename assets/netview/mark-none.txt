# ROUND NETVIEW, addendum: THE MARK ON A PROGRAM. Twelve by twelve, so
# that it fits beside the text on a 22-pixel-high taskbar button and in a
# 22-pixel-high title bar.
#
# THREE MARKS AND NO FOURTH. `real` -- the normal case -- gets NO mark
# at all. A mark on every window would be a screen full of signs that
# say nothing, and the one sign that means something would drown in it.
#
# ONE FAMILY: every mark is a ring, so that anybody who has seen one
# knows the next one is about the same thing. What differs is the shape
# INSIDE the ring, never only the colour: a SLASH, which is what a crossed-out thing has looked like for a century.
# . =
# I = @ink
# D = @dim
# W = @warn
