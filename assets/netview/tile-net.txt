# ROUND NETVIEW, THIRD ADDENDUM: the tile that takes the machine's
# address away and gives it back. Two connectors, joined -- a cable,
# which is the only kind of network this tree has (there is not one
# line of 802.11 in it, and a radio symbol for something that does not
# exist would be the worst shortcut in a round about not lying).
#
# ------------------------------------------------------------------
# WHY THERE ARE THREE TILE DRAWINGS AND NOT SIX.
#
# The obvious build is two drawings per tile, one for on and one for
# off, so that a person who cannot tell the colours apart can still see
# which way the switch stands. It was drawn that way first and then
# MEASURED, and it failed its own test: a sixteen-by-sixteen glyph is
# mostly outline, so "the same shape with the middle changed" comes out
# at about a quarter of the pixels different -- under the third that
# `icons.py` demands, and rightly, because a quarter is not a
# difference somebody sees at a glance.
#
# So the switch position is carried by THREE things that are not the
# glyph and only one of which is colour:
#
#   1. THE WORD under the tile: "an" or "aus". Not a hue, a word.
#   2. THE FRAME: raised when off, sunken when on (`wlibc.frame3`,
#      the same relief every button in this system has had since K15).
#   3. the fill, which IS colour, and which is therefore the one of
#      the three nobody has to be able to see.
#
# That is how a toggle actually tells you where it stands, and it is
# more honest than six drawings of which three pairs differ by a
# quarter and pretend to be legible.
# . =
# I = @ink
# A = @accent
