# Osum vs Linux: speed comparison

Generated by `tools/speedcmp/run.sh` (run it through `/root/jarvis/bin/heavy`). The same musl-linked C program (`tools/speedcmp/speedbench.c`, dynamic, same `libc.so`) runs once per boot under Osum and under Debian 13 (kernel booted with `init=` straight into the bench, no daemons) in QEMU/KVM with the same CPU model, vCPU count, RAM and disk type. Each value is the median of 5 boots; raw min/max are in `docs/speed-osum-vs-linux.tsv`. Factor above 1 means Osum is slower. Analysis: `docs/speed-osum-vs-linux-analysis.md`.
