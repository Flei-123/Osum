# PLAN-SWR-VULKAN -- software Vulkan on OrientOS (one page, 22.10.2026)

Detail: `docs/GPU-PLAN.md` (options, risks), `docs/GFX-STACK.md` (measurements, Vulkan call list). This page is the short plan.

## State (measured)
- Rasteriser `lib/gpu/swr/{raster,shader,scene}.fi`: fill rule, depth, texture bit-exact, VM = native, 1 = 4 threads; `tools/gfx/run.sh` 10/0.
- SPIR-V `lib/spirv/{parse,validate,lower,spv}.fi`: parser, validator, lowering to SWR bytecode; `tools/spirv/run.sh` 36/0 (glslang + spirv-val cross-check, fuzz, f64 reference).
- Speed (release-fast): 1240x720 textured quad 31.8 ms on 1 core (9.7 ms on 4); 4000 triangles 194.8 ms on 1 core (30.7 ms on 8); shader VM 1.3 ns per op and pixel; lowered SPIR-V 1.7 ns (arithmetic) to 6.8 ns (sin/cos/exp2/log2).
- ICD loading: a 10-function Firn `.so` named `libvulkan.so.1` loads in the Osum loader (`tools/gpu3` 9/0, r1376).

- API layer slice 1 (04.11.2026): `lib/vulkan/*` builds `libvulkan.so.1` (`firnc --shared lib/vulkan/libvulkan.fi`, monolithic ICD, 57 `vk*` exports incl. `vkGetInstanceProcAddr`/`vkGetDeviceProcAddr`): instance, physical device (type CPU, 1.3), device, queue, memory, buffer, image (RGBA8/BGRA8), command pool/buffer, clear/copy/fill commands, fences, semaphores. `vkproc.fi` is generated by `tools/vulkan/genproc.py`. Gate `tools/vulkan/run.sh`: the same C client against lavapipe and the ICD, 5 readback hashes byte-identical, 5 mutation counter-proofs, 13/0.

## Gaps
- Rasteriser: no clipping, mip, MSAA, stencil, tile binning (r683). Done 23.10.: scissor, source-over blending (submission order, thread independent), 8-bit bilinear (`lib/gpu/swr/pixel.fi`, `tools/gfx` 21/0).
- Lowering: discard + late-Z, 3 samplers, uniform blocks / push constants (constant indices, `OP_LDU`) and the vertex stage (`lower_stage`, `lib/gpu/swr/vertex.fi`) done 23.10. Missing: loops, dynamic uniform array index, integer ops, texelFetch, flat varyings > 2 locations, derivatives (r732, r733); transcendental ops slow (r738).
- Vulkan API layer covers 57 of the 83 functions of the Daidalos RHI list (GFX-STACK ch. 6); missing: shader module, pipeline, descriptor set, render pass / dynamic rendering, draw, image view, sampler, swapchain/WSI into `wl_shm` (r1375, r737).
- No guest client has rendered through the ICD yet (r1412).

## Stages
1. **A -- fUi on software Vulkan:** lowering for the fUi shaders (discard + late-Z, vertex stage, 3+ samplers), clipping (near plane done: lib/gpu/swr/clip.fi, tools/gfx test_clip) + blending + bilinear (r1374, r684, r683). Gate: fUi frame through SWR equals the native frame. Done for a fUi-style rect shader pair (`tools/gfx/test_fui.fi`, 12/0, pixel exact vs a native Firn model); the real `gpu_fs.glsl` (7 flat vec4 inputs, integer shifts, texelFetch, loop, uniform vec4[8] with dynamic index) is still out of reach.
2. **B -- API layer + WSI:** Instance/Device/Pipeline/Swapchain as `libvulkan.so.1`, offscreen read-back into `wl_shm` (r737, r1375). Gate: `vulkaninfo`-like client lists the device in the guest.
3. **C -- milestone:** a vkcube-like client renders in the guest, >= 30 fps at 640x480 on 4 cores (r1412).
4. **D -- speed:** Firn SIMD or x86-64 JIT for the VM after measuring the real `mesh.frag`, tile binning, f32 transcendentals (r738, r675). Then compute + storage buffers for wgpu (T2).

## Next (Stage A rest)
1. Shader module + graphics pipeline (SPIR-V -> `lower.lower_stage` vertex/fragment, fixed-function state -> Frame flags).
2. Image views, samplers, descriptor sets (UBO/push constants via `Frame.ubo`, 4 texture slots), vkCmdBeginRendering/EndRendering/Draw/BindVertexBuffers.
3. Gate: triangle + textured quad + fUi rect pair vs lavapipe (mean/max), `FUI_GPU_VALIDATE=1` clean.
4. Guest: `tools/gpu3` style load of the real `libvulkan.so.1` in OrientOS, then WSI by read-back into `wl_shm`, then `gpu_vk.fi` on the guest.
5. Hardware (Intel HD 620 Gen9) = a second executor behind the same objects (H0 probe first); virtio-gpu 3D / virgl stay parked.

## Rules
- Every gate has a counter-proof (variant that bypasses the new code must go red).
- Measure with `--opt-level=release-fast`; default `firnc` checks overflow and is 4x slower.
- Real GPU drivers and VM 3D (VMSVGA/virtio-gpu 3D) stay parked until stage C is green (GPU-PLAN option 2/3).
