# Je Zeile: `schicht modul`. Der Modulname ist der Dateiname ohne `.fi`,
# denn genau so spricht Firn ein Modul an (letzter Pfadteil des
# `import`). Diese Datei ist die EINZIGE Wahrheit fuer
# `tools/struktur/run.sh`; wer eine Datei verschiebt, aendert hier die
# Zeile mit.
#
# Erfasst sind NUR die 137 Dateien, die das Kernabbild wirklich
# erreicht (`tools/struktur/huelle.py`). `kernel/user/` (188 Dateien)
# und `kernel/app/` (15) sind eigene Programme mit eigenen Wurzeln und
# gehoeren NICHT in dieses Modell.
#
# ---------------------------------------------------------------- DIE REGEL
#
# Ein kleinerer Rang liegt WEITER UNTEN. Eine Schicht darf nur Module
# gleichen oder kleineren Ranges rufen. Gleicher Rang ist erlaubt
# (innerhalb einer Schicht kennt man sich), groesserer Rang ist ein
# BRUCH: ein Plattentreiber darf das Fenster nicht rufen, die
# Oberflaeche aber sehr wohl die Platte.
#
# ---------------------------------- WARUM ES EINE SCHICHT `glue` GIBT
#
# Ein Betriebssystem hat Module, deren AUFGABE es ist, von oben nach
# unten zu greifen: der Unterbrechungsverteiler (`trap`) muss die
# Tastatur, die Platte, die Uhr und das Netz erreichen, sonst verteilt
# er nichts. Dasselbe gilt fuer den Start der anderen Prozessoren
# (`smp`), die Daueraufgaben (`tasks`), das Schlafenlegen (`schlaf`,
# `susp`, `wach`) und die Geraeteuebersicht (`hw`, `hwdiag`).
#
# Diese Module als "Bruch" zu zaehlen waere unehrlich -- sie brechen
# nichts, sie SIND die Verdrahtung. Sie stehen deshalb in `glue`, ganz
# oben unter `boot`, und duerfen nach unten rufen. Was sie NICHT
# duerfen: einander ersetzen oder von unten gerufen werden.
#
