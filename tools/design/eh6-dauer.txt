# Justins Foto nach 42 MINUTEN Laufzeit zeigt eine ZERRISSENE
# Diagnosetafel: Bloecke gegeneinander versetzt, Zeile 9 (CALIB) und
# Zeile 21 (FOUND) halb ueberschrieben. Dazu die Zahlen
#     4  RING 23320 VERL 8908 KOAL 57944
#     16 ISR MAX 21265 TVERL 4358 SPAET 10 LM 2091
#     8  TICK IRQ 250145 MAL 62713 LOOP 37378
#
# ECHTHARDWARE-5 hat unter Last `RING 98 VERL 0 KOAL 0` gemeldet -- und
# genau das ist der Punkt: der Fehler braucht MINUTEN BIS STUNDEN, und
# ein Laeufer, der zwei Minuten misst, findet ihn per Bauart nicht.
#
# Dieses Drehbuch zieht deshalb IN EINER SCHLEIFE und misst zwischen
# den Runden. Es ist absichtlich eintoenig: es geht nicht darum, viele
# verschiedene Dinge zu tun, sondern DIESELBE Sache oft genug, dass ein
# Zaehler ueberlaufen oder ein Ring volllaufen kann.
#
# Die Tafel meldet sich bei jedem Anstrich selbst auf die serielle
# Leitung; `RING/VERL/KOAL` stehen in Zeile 4, der Bildspeicher wird
# ueber die Bilder geprueft (`tools/design/eh6mess.py`).
