# Justins Tafelzeile 18 lautet auf dem Blech
#     18 KEYS  D 2 BER 0 ARM 1 CC 0 RK 00000000 N 0
# also: ein Block wurde EINMAL auf den Ring gelegt (ARM 1) und ist NIE
# fertig geworden (BER 0). Zeile 20 sagt dazu `KBD EP1 F0 H0` -- der
# Endpunkt laeuft, hat keinen Fehler und musste nie wiederbelebt
# werden. Ein angehaltener Endpunkt ist es also NICHT.
#
# Dieses Drehbuch tippt in das Suchfenster und fotografiert die Tafel
# davor und danach. Was zaehlt, sind die Zahlen in Zeile 18 -- die
# serielle Leitung traegt dieselbe Zeile mit (`tafel: 18 KEYS ...`).
