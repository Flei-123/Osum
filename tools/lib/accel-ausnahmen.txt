# tools/lib/accel-ausnahmen.txt -- ABSCHNITTE, DIE AUF TCG BLEIBEN.
#
# Format je Zeile:   <schluessel>   <begruendung>
# Der Schluessel ist der Verzeichnisname des Laeufers: tools/k16/run.sh
# -> "k16", tests/theme/run.sh -> "theme".
#
# Ein Eintrag hier heisst: dieser Abschnitt laeuft auf TCG, OBWOHL /dev/kvm
# da ist. Das kostet Zeit, also braucht jeder Eintrag einen GEMESSENEN
# Grund -- nicht eine Vermutung. Wer einen Eintrag entfernt, muss den
# Abschnitt vorher unter KVM gruen gemessen haben.
#
# NICHT hier stehen die drei, die von vornherein nicht umgestellt wurden;
# sie setzen ihr `-accel` selbst im Quelltext bzw. sind ein anderer Bogen:
#   tools/hv/run.sh    -accel tcg, misst dass TCG kein VT-x kann
#   tools/smp/run.sh   -accel tcg,thread=single|multi, misst genau das
#   tools/arm/run.sh   qemu-system-aarch64, KVM auf x86 unmoeglich
#
# Zum Messen laesst sich diese Liste mit OSUM_ACCEL_FORCE=1 abschalten,
# und OSUM_ACCEL=tcg|kvm schlaegt sie ohnehin.
