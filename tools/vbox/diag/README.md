# tools/vbox/diag -- laptop-side VirtualBox diagnosis helpers (copy to C:\Users\justi\vbl\)
- `allcpu.ps1 -Sec N`: host CPU per VirtualBoxVM/VBoxHeadless pid (boss VM vs headless test VM; headless = VBoxHeadless, NOT VirtualBoxVM).
- `regs.ps1 -N n`: rip/rsp/cr3/rflags per vCPU (debugvm). Resolve: `nm -n <image dir>/osum.mb`; rflags bit 0x200 = IF. All vCPUs in idt.halt/sched.idle_wait+0x8c (HLT) while the host burns a core = host/VMM side wake storm, not a guest spin.
- `threads.ps1`: per-thread CPU of the test VM process.
Restart order after a VM restart: kill the `python` odbc proxy + delete odb.proxy.pid BEFORE `start`, else odbwait attaches to the dead pipe.
- `tm.ps1 -Sec N`: two `debugvm statistics` samples of the test VM: per-vCPU executing/halted/other as % of wall time (/TM/CPU/NN/cNs*) and the biggest NEM/EM/PDM per-second rates (ExitHalt, ExitPortIo, ...). In the 99 % state compare halted% vs host CPU.
- `ab.ps1 -Url .. -ShaXz .. -ShaRaw .. -Tag t [-Odb 0]` (Odb 0 = no COM2, no agent: classified by host CPU, BURN line): one whole A/B round in the background (stop, fetch, swapdisk, start headless, ODB, login, settle, host CPU samples, tm); log `C:\Users\justi\vbl\ab-<Tag>.log`. Start via Invoke-CimMethod Win32_Process Create. Boss VM shows up as the other ~100 % pid (noise).
- `bossmatrix.ps1 [-Boots 3 -Samples 4 -Sec 15 -Only pv_none,runloop0 -Gui]` (r1268 step 3): unattended VM-setting matrix on the boss VM (BASE = 1 vCPU, hpet/x2apic off; one change per config: paravirt none/kvm/hyperv/minimal, NEM UseRing0Runloop 0/1, x2apic, hpet, audio off, vboxvga, ich9, nested-paging/large-pages off, 2 vCPU). Per boot host CPU of the VM pid, BURN > 90 % of a core; log `C:\Users\justi\vbl\bossmatrix.log` (`RESULT <cfg> burn_boots=b/n`, `=== SUMMARY`). ~3 min per boot -> full matrix ~2.5 h. Start via Invoke-CimMethod Win32_Process Create, poll the log. Leaves the VM off with BASE settings (1 vCPU); original dump in `bossmatrix-orig-*.txt`.
- `stab1.ps1 [-Names OrientOS,OrientOS-Test] [-Boots 1] [-Settle 90] [-Gui] [-NoLogin] [-Trace]` (taskbar output is OFF without /etc/uitrace: `-Trace` types `touch /etc/uitrace` once per VM, guest layout is DEU: y/z swapped, `-` = 35, `/` = shift+7) (STAB-1): cold boot each VM with UART1 -> `C:\Users\justi\vbl\stab1-<vm>-<n>.txt`, log `stab1.log` (`STAB1 DONE`). Fetch the two files, then on the server: `python3 tools/stab/report.py --boss <boss file> --test <test file> --out report.md` (verdict: bar up? conf / geometry / icons ruled out?). Start via Invoke-CimMethod Win32_Process Create. Host test of the report: `bash tools/stab/report-test.sh` (8/0).
- `bench2.ps1 [-Names ..] [-Samples 5 -Sec 15 -Settle 60]` (BENCH-2): per VM one headless boot, login, settle, then N samples of host CPU % of the VM process + VirtualSync lag; log `C:\Users\justiblench2.log` (`BENCH2 DONE`). Start via Win32_Process Create.
